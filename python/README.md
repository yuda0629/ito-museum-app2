# 伊都国遺跡マップ

福岡県糸島市に広がる伊都国の遺跡を地図上に可視化するアプリです。

## 機能

- **カラーピン表示** — 遺跡の種類（王墓・首長墓・集落など）ごとに色分けしたピンを地図に表示
- **キーワード検索** — 遺跡名・種類・時代・説明文をスペース区切りの AND 検索
- **時代フィルター** — 弥生・古墳・奈良など複数の時代を選択して絞り込み
- **詳細表示** — マーカーまたは一覧から遺跡を選ぶと、種類・時代・説明・座標を表示
- **凡例** — 種類と色の対応をパネルに表示

## 使い方

1. 地図上のピンをクリック、または左パネルの一覧から遺跡を選ぶ
2. 検索ボックスにキーワードを入力して絞り込む（例: `王墓 弥生`）
3. 時代フィルターで表示する時代を選ぶ（Ctrl/Command で複数選択）

## 技術スタック

| 役割 | ライブラリ |
|------|-----------|
| UI フレームワーク | Streamlit |
| 地図描画 | Folium / Leaflet |
| データ処理 | pandas |

## データ

`ito_sites_clean.csv` に遺跡データを格納しています。独自の CSV をアップロードして使用することも可能です（必須列: `name`, `lat`, `lng`）。
